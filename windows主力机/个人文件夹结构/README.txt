00-公共目录 --- Public
    核心定位：存放公司下发的宏观文件及个人日常汇报材料。此区域为“只读或低频查阅”区，不存放核心业务产出。
        人事：劳动合同、社保公积金记录、个人工资条等。
        通知：公司红头文件、行政通知、放假安排、微信群重要通知及时转存等。
        考勤：请假单、打卡异常申诉记录等。
        财务：报销发票、差旅报销单、付款凭证等。
        入职：新员工入职指南、开发环境配置文档、账号申请流程等。
        汇报：个人日报、周报、月报、阶段性工作总结等。

01-项目需求 --- Project
    核心定位：个人业务主阵地，存放你负责的具体项目需求及后续维护材料。
        命名规范：按项目名建文件夹，能看出来你所维护的项目即可（如 某项目）。
        存放内容：需求文档、原型图、验收材料、项目沟通纪要等。

02-备份文件 --- Backup
	核心定位：存放跨设备迁移时最核心的数字资产，防丢失、防扯皮。
        企业账户：公司开通的各类后台账号、服务器密码、第三方服务Key等。
        软件配置：IDEA/VSCode配置、Maven/Gradle配置、Git配置、浏览器书签及插件包等。

03-工作代码 --- Coding
    核心定位：按工程化思维分类，将“运维动作”、“底层基座”与“业务脚本”彻底隔离。（写代码的主战场）
        deploy\：部署项目发版本（同步维护的项目、发版脚本、CI/CD配置）。
        work-script-java\：基于 Java 编程的代码（工具类、算法验证、临时接口等）。
        work-script-python\：基于 Python 编程的代码（自动化脚本、爬虫、数据处理等）。
        work-script-node\：基于前端/Node的代码（前端脚本、自动化测试、构建工具等）。
