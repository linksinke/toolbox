Git 仓库下载并命名
==========================================
作用：输入 git 地址（HTTP / HTTPS / SSH），带进度克隆到本地，
并按「仓库末段名 + 年月日时分」命名目录。


一、命名规则
--------------------------------------
地址：
  https://github.com/owner/repo.git

取末段名：
  repo.git

加上时间（yyyyMMddHHmm）：
  repo.git.202610121455


二、用法
--------------------------------------
1. 双击或在 PowerShell 中运行：
   .\git仓库下载并命名.ps1

2. 按提示粘贴 git 地址，例如：
   https://github.com/owner/repo.git
   git@github.com:owner/repo.git

3. 保存目录：直接回车 = 脚本所在目录；也可输入其他路径

4. 看到绿色「克隆完成」即成功


三、命令行参数（可选）
--------------------------------------
.\git仓库下载并命名.ps1 "<git地址>"
.\git仓库下载并命名.ps1 "<git地址>" "<保存目录>"


四、说明
--------
- 克隆过程会实时显示 git 进度（Receiving objects: xx% 等）
- 若长时间连不上远端，每约 8 秒会提示「仍在克隆中」（多为网络慢，并非卡死）
- 失败时会尽量删除不完整目录，并提示常见原因（权限/网络/SSH）
- 需本机已安装 Git，且 HTTPS/SSH 鉴权可用
